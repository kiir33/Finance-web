# Agent Workspace

This directory contains all artifacts generated by AI agents working on this repository.

## Structure

```
.agents/
├── config/              # Agent configurations & model assignments
│   ├── lead-agent.yaml  # Lead engineer (Nemotron) config
│   ├── worker-agents.yaml  # Junior engineers config
│   └── reviewer-agents.yaml  # PR reviewers config
├── docs/                # Agent-generated documentation
│   └── architecture/    # Architecture decision records (ADRs)
├── prompts/             # System prompts for each agent role
├── workflows/           # Multi-agent workflow definitions
├── rules/               # Development workflow rules
├── bin/                 # Helper scripts (clean-stale, clean-worktrees, model-enforce)
├── logs/                # Execution logs (gitignored)
└── .gitignore
```

## Conventions

- **All agent-generated markdown** goes in `.agents/docs/` (working)
- **Prompts** are versioned in `.agents/prompts/`
- **Logs** in `.agents/logs/` are ephemeral (`.gitignore`d)
- **Co-author attribution** required on all agent commits/PRs/comments

## Source of Truth (Cross-Repo)

Agent roles, model assignments, and the multi-agent implementation flow are defined in the FinanceApp Knowledge Base:

- [[../FinanceApp-KnowledgeBase/AGENTS_AND_IMPLEMENTATION_FLOW.md]] — agent roles, implementation flow, worktree isolation, board tracking, co-author convention

This repo's `.agents/` directory contains repo-specific overrides (prompts, rules, workflows) that implement the KB flow for the backend + web platform.
